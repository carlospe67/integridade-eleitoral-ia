# Projeto de IA: Integridade Eleitoral

Este workspace apoia o projeto individual da disciplina **Inteligência Artificial: Fundamentos e Aplicações**, da Universidade Federal Fluminense (UFF).

O projeto aplica aprendizado de máquina espacial e processamento de linguagem natural à detecção exploratória de anomalias eleitorais associadas a coação territorial e compra de votos. A documentação inicial, o escopo e o plano metodológico estão em [projeto_eleitoral/README.md](projeto_eleitoral/README.md).

Os entregáveis previstos são:

- relatório técnico;
- apresentação em slides;
- vídeo demonstrativo;
- código-fonte, notebooks e arquivos de dados utilizados.

## Estrutura do workspace

Welcome to the Artificial Intelligence course! This project is designed to provide a comprehensive understanding of various AI concepts and techniques. Below is an overview of the course structure and the topics covered.

## Course Structure

- **Lessons**: The course is divided into several lessons, each focusing on a specific area of artificial intelligence:
  - **Fundamentals**: Introduction to basic AI concepts, definitions, and principles.
  - **Machine Learning**: Exploration of machine learning techniques, algorithms, and their applications.
  - **Deep Learning**: In-depth study of deep learning architectures and frameworks.
  - **Natural Language Processing**: Techniques for processing and analyzing human language data.

- **Exercises**: Practical exercises that allow students to apply the knowledge gained from the lessons.

- **Projects**: Larger projects designed for students to demonstrate their understanding of AI concepts.

- **Notebooks**: Jupyter notebooks for interactive coding and experimentation with AI algorithms and datasets.

- **Source Code**: The `src` directory contains:
  - **Algorithms**: Implementations of various AI algorithms.
  - **Datasets**: Scripts for loading and processing datasets.
  - **Utils**: Utility functions and helper modules.

- **Tests**: A directory for unit tests and other testing scripts to ensure code correctness.

- **Requirements**: The `requirements.txt` file lists all necessary Python dependencies for the project.

## Getting Started

To get started with the AI course, please follow the instructions below:

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies using the command:
   ```
   pip install -r requirements.txt
   ```
4. Explore the lessons, complete the exercises, and work on the projects to enhance your understanding of artificial intelligence.
